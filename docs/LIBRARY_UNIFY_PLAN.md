# 서재 통일 · 만화 보기 다듬기 계획 (2026-10-03 확정: 9건 모두 권고안)

사용자 요청 다섯 가지 — (가) 만화 탭 갈래를 책과 같게, (나) 보기 도구를 탭 전체에, 책장 보기 추가,
(다) 좌우 밀기는 책 ↔ 만화 오가기, (라) 만화는 쪽이 붙어 넘어가고 태블릿은 두 쪽, (마) 오→왼 진행 막대 방향 통일.
구상안 그림: unify-board-1~4(작업 공간, 저장소에 넣지 않음).

## 2. 분석 — 여러 권 작품의 "읽는 중" 경계

- 권 단위로 나누면 한 작품이 세 갈래에 흩어진다(1~3권 다 읽음, 4권 읽는 중, 5권~ 읽을). 서재가 조각난다.
- 작품 단위 집계(Komga 식)가 가장 덜 놀랍다:
  - 한 권이라도 열었고 전부 끝나지는 않음 → **읽는 중**
  - 모든 권 끝 → **다 읽은**
  - 아무 권도 안 엶 → **읽을**
- 경계 사례
  - 다 읽은 작품에 새 권이 들어옴 → 읽는 중으로 돌아가고 "새 권" 표시(안 그러면 새 권이 다 읽은 칸에 묻힌다).
  - 1권만 펼쳐 보고 그만둠 → 읽는 중. 길게 눌러 옮기기(책과 같은 수동 이동)로 바로잡는다. 수동 지정이 집계보다 앞선다.
  - 대안: "마지막 권을 끝냈으면 다 읽음" — 중간 권을 건너뛴 사람에게 맞지만, 순서 정렬이 틀린 작품에서 잘못 판정한다.

## 3. 결정할 것 (★ 권고)

1. 만화 탭 갈래 — ★ 책과 같은 세 갈래(읽는 중 / 다 읽은 작품 / 읽을 작품), 작품 단위.
2. 작품 상태 기준 — ★ 집계(위 §2) + 길게 눌러 수동 이동 + 새 권 들어오면 읽는 중으로. 대안: 마지막 권 기준.
3. 보기 도구 위치 — ★ 탭 바로 아래 한 줄, 탭 전체에 적용. 정렬: 최근 읽은 순(기본) / 이름 / 추가 / 크기. 대안: 갈래마다.
4. 보기 종류 — ★ 격자 · 목록 · **책장** 셋.
5. 책장 모양 — ★ 가: 나무 책장(밝음 · 어두움 두 결) / 나: OLO 단색 선반.
6. 좌우 밀기 — ★ 탭 넘기기(책 ↔ 만화). 읽는 중 줄은 옆으로 밀리지 않고 다른 갈래처럼 줄바꿈. 대안: 가로 줄 유지(몸짓 충돌).
7. 만화 넘김 — ★ 쪽이 붙은 채 손가락을 따라 미끄러지는 넘김(말림 효과 없음). 두 쪽에 걸친 그림이 이어 보인다. 대안: 책 설정 따름(현재).
8. 두 쪽 기본 — ★ 기본값을 "넓은 화면에서"(태블릿 · 펼친 폴더블은 세로에서도, 휴대폰은 가로에서만). 대안: 가로에서만(현재).
9. 오→왼 진행 막대 — ★ 위 슬라이더 · 아래 막대 모두 오른쪽에서 채운다(읽는 방향). 대안: 둘 다 왼쪽에서.

## 4. 구현 순서 (진행: U1 0.38.0 끝)

U1 서재: 만화 갈래 · 집계 · 보기 도구 한 줄 · 탭 밀기 → U2 책장 보기 → U3 만화 붙은 넘김 · 두 쪽 기본 → U4 오→왼 막대.
각 단계는 버전 하나, 일부러 망가뜨린 입력 시험(빈 작품, 권 수 0, 새 권 추가, 방향 뒤집힘)을 함께 둔다.
