# 서재 구조 계획안 — 책과 만화 구분 · 만화 모으기 · 작품 묶기 (초안, 2026-10-02)

> 상태: **확정 (2026-10-02 사용자 결정: 권고안 7건 모두 ★).** 뷰어(`docs/COMIC_PLAN.md`)보다 먼저 정했다(사용자
> 지시) — 무엇을 한 권으로 보고 어디에 놓는지가 정해져야 이어 읽기 · 다음 권 · 진도의 단위가 정해진다. 구현 단계:
> L1 순수 코어(`:document` `comic/`) → L2 훑기 · 데이터 → L3 화면(0.33.0). 뷰어는 그 뒤.

## 1. 지금 서재

- 사용자가 **폴더를 등록**하면 그 아래를 재귀로 훑어(`LibraryScanner`, 깊이 20) EPUB · TXT · PDF 를 찾는다.
- 책 하나가 `books` 표의 한 행이다. 열쇠는 문서 URI. 등록 폴더(`folderUri`)는 기억하지만, **책이 들어 있던 하위 폴더는
  기억하지 않는다.** 만화를 작품으로 묶으려면 이것을 더 알아야 한다.
- 홈은 평평한 한 목록이다: 읽는 중 · 읽은 책 · 읽을 책 책장, 격자 · 목록, 이름 · 추가한 순 · 크기순, 찾기.

## 2. 조사 요약

Komga · Kavita · Mihon 은 원본 코드를 읽었다. 상용 앱은 검색 요약과 도움말에 기댔다(일부 [미확인]).

| 앱 | 책 · 만화 | 무엇으로 묶나 | 흩어진 폴더 | 합본 |
|---|---|---|---|---|
| Komga | 서재(라이브러리)를 따로 만든다 | 폴더 = 시리즈 | 안 합친다 | 파일 하나 = 책 하나 |
| Kavita | 서재 종류(만화 · 코믹 · 책 · 그림) | ComicInfo → 파일 이름 → 폴더 | **합친다**(정규화한 이름 + 같은 형식) | Format 으로 특별편 처리. 한국어 권 범위는 못 읽는다 |
| Mihon 로컬 | 만화 전용 | 맨 위 폴더 | 안 합친다 | 하위 폴더 = 화 |
| ComicRack | 만화 전용 | Series + Volume | **합친다**(메타데이터) | 손으로 |
| Kindle | 한 서재 + Comics 거르기 | 상점 시리즈. "시리즈 묶기" 를 켜면 첫 권 표지 + 권 수 | — | — |
| Play 북 | 한 서재 + Series 탭 | 상점 시리즈 | — | — |
| 리디 | 한 서재 + 갈래 거르기 | 단행본은 권, 연재는 화 단위로 묶어 **시리즈 하나를 하나로 센다** | — | — |
| ReadEra · Moon+ | 한 서재(섞임) + 시리즈 · 폴더 칸 | 메타데이터 | — | — |

정리:
- 로컬 파일 앱은 거의 모두 "폴더 = 시리즈" 다. 흩어진 것을 합치는 앱은 Kavita · ComicRack 뿐이다.
- 상용 서재는 모두 **한 서재 + 형식 거르기 + 시리즈 묶음 카드**로 모인다.
- Kavita 의 한국어 규칙은 쓸 만하다. 권은 `제?(\d+(\.\d+)?)(권|장)`, 화는 `(\d+)(회|화|장)`, 완결은 `(완|완결|完)` 이다.
  다만 "1-10권" 범위와 외전 · 특별편 · 0권은 따로 다루지 않는다 — 우리가 더한다.

## 3. 결론 모형 (권고)

1. **등록은 지금처럼 폴더 하나로.** 훑을 때 종류를 스스로 가린다.
   - 만화: cbz/cbr/cb7/cbt
   - 만화 후보: 그림만 든 zip, 그림 3장 이상만 든 폴더. `cover.jpg` 처럼 한두 장뿐인 폴더는 아니다.
   - 책: EPUB · TXT · PDF
   - 섞인 폴더도 그대로 받는다.
2. **서재 한 화면 + 위 탭 [책 · 만화].** 만화 탭의 칸은 **작품**(시리즈)이고, 누르면 작품 화면(권 · 화 목록)이 열린다.
   웹툰은 만화 탭 안의 작품이다(종류 표시 "웹툰", 단위는 화).
3. **작품 묶기 — 이름 열쇠.** 이름이 같으면 어느 폴더에 있든 한 작품이다(Kavita 방식). 다음 순서로 정한다. 앞 단계가
   "정하지 않음"(null)이면 다음 단계로 간다(규칙 5).
   1. 손으로 고친 것
   2. ComicInfo `Series` · `Number`. 한국 만화는 Number 가 권이다 — 미국식 Volume 은 판본이라 뜻이 다르다.
   3. 파일 이름
   4. 폴더 이름(파일 이름에 작품 이름이 없을 때)
4. **작품 정리**로 틀린 것을 고친다: 합치기 · 빼기 · 이름 고치기 · 같은 권 고르기. 고친 값은 파일 URI 와 이름 열쇠로
   저장해 **다시 훑어도 남는다**.

## 4. 이름 읽기 규칙 (코어, 순수 Kotlin — 기기 없이 시험)

**1. 다듬기** — 확장자 · 앞쪽 `[작가]` · 모든 `( )` `[ ]` `{ }` 꼬리표(연도 · 해상도 · Digital · 그룹)를 지운다.
완결 표시 `(완)` `[완결]` `(完)` 는 따로 "완결" 깃발로 남긴다. `_` 와 `.` 은 띄어쓰기로 바꾼다.

**2. 번호** — 위에서부터 먼저 맞는 것을 쓴다.

| 종류 | 형태 | 결과 |
|---|---|---|
| 범위 | `4-6권` · `1~10권` · `v01-03` · `001-050화` | **합본** |
| 권 | `제 3권` · `3권` · `v3` · `vol.3` · `3巻` | 권 번호 |
| 화 | `17화` · `17회` · `ch.17` · `ep17` | 화 번호 |
| 부 · 시즌 | `2부` · `시즌2` · `S2` | 상위 정렬 열쇠 |
| 특별편 | `외전` · `특별편` · `번외` · `단편` · `SP` · `0권` | 특별편 |
| 아무 표시 없음 | 끝의 숫자 | 번호. 1900~2099 네 자리는 연도라 버린다 |

**3. 작품 이름** — 번호 앞의 글이다. 비면 부모 폴더 이름을 같은 규칙으로 다듬는다. "01권" 처럼 번호뿐인 폴더라면 그 위
폴더를 쓴다.

**4. 이름 열쇠** — 유니코드 정규화(NFC) → 소문자 → 글자 · 숫자 밖의 것을 지운다(한글은 남는다) → 전각을 반각으로.
"원피스 01" 과 "[오다] 원피스 02권 (완)" 은 둘 다 `원피스` 다. "원피스 필름" 은 다른 작품이다 — 맞다.

**5. 순서** — (부, 권, 화, 특별편은 끝, 자연 정렬) 순. 12.5 는 12 와 13 사이에 온다.

**6. 웹툰** — `작품/001화/*.jpg` 는 작품 폴더 안의 그림 폴더 하나가 한 화다. `작품/1부/001화/…` 도 같다.

**7. 합본** — 파일 하나가 한 단위다. 안에 권 · 화로 읽히는 하위 폴더가 있으면 **안의 목차**로 들여 보인다(UI 규칙 1).
낱권과 합본이 겹치면 둘 다 보이고, 합본에 "겹치는 권" 을 표시한다.

**8. 같은 권 여러 곳** — (열쇠, 번호)가 같고 크기도 같으면 같은 파일이다. 하나만 보이고 "같은 권 n곳" 을 표시한다.
크기가 다르면 판본이라 고를 수 있게 한다. 진도는 고른 파일 하나에만 건다.

**9. 관대함** — 깨진 압축 · 잘못된 ComicInfo · 읽지 못한 이름은 그 단위만 "분류 안 됨" 작품에 넣고 계속 훑는다(규칙 6).

**10. 섞지 않는 것** — EPUB · PDF 와 만화 압축은 이름이 같아도 한 작품으로 합치지 않는다(Kavita 의 형식 가드).
고정 레이아웃 EPUB 만화 · 스캔 PDF 만화는 자동으로 가르지 않고 책 메뉴의 "만화로 보기" 로 옮긴다(결정 7).

## 5. 데이터 (이후 코딩의 줄기)

- `books` 에 단위 종류(책 · 만화 · 웹툰화)와 **들어 있던 폴더 경로**를 더한다. 훑을 때 이미 지나가는 값이다.
- 새 표 `works`(작품: 이름 열쇠 · 보이는 이름 · 종류 · 넘기는 방향 · 완결)를 두고, `books.workKey` 로 잇는다.
- 새 표 `work_overrides`(손으로 고친 것)를 둔다.
- 진도 · 책갈피는 지금처럼 **파일(권 · 화)마다** 둔다. 작품의 "읽는 중" 은 그 안 권들의 진도에서 계산한다.
- 묶기는 순수 함수로 짠다: 훑은 목록 + 고친 것 → 작품 목록. 같은 입력이면 같은 결과다. 시험이 지키는 것:
  - 흩어진 폴더를 합친다
  - 합본을 알아본다
  - 같은 권을 알아본다
  - 깨진 이름도 버리지 않는다
  - 고친 것이 다시 훑어도 남는다

## 6. 구상안

| 판 | 화면 |
|---|---|
| ① 서재 갈래 세 안 | 가안 ★ 한 서재 + 위 탭(책 · 만화) / 나안 섞고 거르기 칩 / 다안 아래 탭으로 따로 |
| ② 작품 화면 | 머리: 작품 이름 · "만화 · 12권 · 2곳에서 모음 · 오→왼". "3권 이어 보기" 단추, 권 목록(진도 막대). 같은 권 2곳 꼬리표, 합본 안의 권은 들여씀, 외전은 끝 |
| ② 작품 정리 | 모은 곳(폴더별 권), 다른 작품과 합치기 · 이 작품에서 빼기 · 이름 고치기 · 같은 권 고르기 |
| ③ 모으는 법 도해 | 실제 폴더 모양 → 서재에 보이는 모양 |

## 7. 결정할 것 (권고는 ★)

1. **책과 만화를 어디에** — ★가. 한 서재 + 위 탭 [책 · 만화](찾기 · 폴더 · 정렬은 함께 쓴다) / 나. 섞어 두고 거르기
   [전체 · 책 · 만화] / 다. 아래 탭으로 화면을 따로.
   - 가안 안에서: 탭 둘 ★ / 셋([전체 · 책 · 만화], 전체는 나안처럼 섞음)
2. **폴더 등록** — ★지금처럼 한 가지. 종류는 앱이 가린다 / 등록할 때 "책 폴더 · 만화 폴더" 를 고른다.
3. **작품 묶기** — ★이름으로 묶고 흩어진 폴더도 합친다 + 손으로 고침(Kavita 방식) / 폴더 하나 = 작품 하나(Komga ·
   Mihon 방식, 흩어지면 따로 보인다).
4. **웹툰** — ★만화 탭 안의 작품(종류 "웹툰", 화 단위) / 탭을 따로.
5. **합본** — ★한 파일은 한 칸, 안의 권은 들여쓴 목차 / 합본을 권별 칸으로 쪼개 보이기.
6. **같은 권 여러 곳** — ★하나만 보이고 "같은 권 n곳", 고를 수 있음 / 모두 따로 보이기.
7. **고정 레이아웃 EPUB · 스캔 PDF 만화** — ★자동으로 가르지 않고 책 메뉴의 "만화로 보기" 로 옮김 / 자동 판정.
