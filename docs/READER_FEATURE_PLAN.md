## 2. 검토 기준

1. **제품 정의**: "EPUB · TXT · PDF 를 간편하게 읽고 책갈피를 꽂는다". 설정이 늘수록 "간편" 이 준다 —
   기본값만으로 잘 읽히고, 설정은 필요한 사람만 찾게 둔다.
2. **권한 없음 · 인터넷 없음**: 지금 앱은 권한이 하나도 없다. 동기화 · 온라인 사전 · 백그라운드 듣기는 이
   원칙을 바꾼다(결정 사항).
3. **구조가 이미 받치는가**: 조판 결과가 글자 오프셋 좌표(run 의 charStart/End · x · 기준선)로 남아 있어
   **글자 찾기(검색) · 글자 고르기(선택) · 칠하기(형광펜)** 가 새 엔진 없이 된다. 저장 위치가 Locator 라
   형광펜 구간도 글자 크기를 바꿔도 미끄러지지 않는다(규칙 3).
4. **PDF 한계**: PdfRenderer 는 글자 층을 주지 않는다 → PDF 의 검색 · 선택 · 형광펜 · 듣기는 Pdfium 전환
   (결정 P1 재검토) 없이는 안 된다. 아래 3·4단계는 **EPUB · TXT 만**이다.

## 3. 단계별 시행계획(안)

난이도: 소(하루 안) · 중(2–3일) · 대(1주 안팎). 각 단계는 따로 배포할 수 있다.

### 1단계 — 읽기 환경 다듬기 (0.12.0, 소 × 9) — **완료**

| # | 기능 | 내용 | 비고 |
|---|---|---|---|
| 1-1 | 배경 테마 | 흰색 · 아이보리 · 회색 · 검정 + "시스템 따름"(기본) | 그리기만 바뀐다(조판 캐시 영향 없음). 세피아 지면은 원래 R4 계획 |
| 1-2 | 여백(문단 너비) | 좁게 · 보통 · 넓게 = 24 · 36 · 48dp (0.13.1 에서 한 칸 넓힘 — 카메라 구멍) | LayoutSpec(규칙 4) |
| 1-3 | 문단 정렬 · 들여쓰기 · 문단 간격 | 정렬 원본/양쪽/왼쪽, 들여쓰기 원본/끔, 문단 간격 좁게/보통/넓게 (리디 대조 R1 · R2) | LayoutSpec(`alignOverride` · `indentOff` 추가) |
| 1-4 | 화면 켜짐 유지 | 읽는 동안 켜 둠: 시스템 · 5분 · 10분 · 항상 | 권한 불필요(창 플래그) |
| 1-5 | 볼륨키 넘김 | 켬/끔(기본 끔) — 켜면 음량↓ = 다음 쪽 | 권한 불필요 |
| 1-6 | 터치 영역 | 기본(좌 앞 · 우 다음) · 좌우 반전 · 양쪽 다음(한 손) | 리디와 같은 구성 |
| 1-7 | 하단 정보 | 왼쪽 · 가운데 · 오른쪽에 각각 없음/책 제목/장 제목/시계/배터리/쪽/진행률/이 장 남은 쪽 (R4, 시계 켬/끔을 대신) | 시스템 바를 숨기므로 시각 · 배터리는 여기서만 보인다 |
| 1-8 | 책갈피 쪽 표시 | 책갈피가 꽂힌 쪽은 오른쪽 위에 리본 표시(사용자 요청 2026-09-24). PDF 는 화면 모서리(쪽 밖) | 윗여백 안에서 끝나 글자를 가리지 않는다 |
| 1-9 | 모서리 눌러 책갈피 | 오른쪽 위 모서리(약 56dp 네모)를 누르면 꽂기 · 빼기, 짧은 안내("책갈피를 꽂았습니다") (D10 사용자 결정) | 그 네모 안에서만 "다음 쪽" 보다 먼저 받는다. 새 부품 CpToast |
| 1-10 | 밝기 막대 | 보기 판의 배경 아래(R3, 2단계에서 당겨 옴). 제스처는 2단계 | 창 밝기, 권한 불필요 |

### 2단계 — 찾기 · 이동 (0.14.0) — **완료**

| # | 기능 | 난이도 | 내용 |
|---|---|:-:|---|
| 2-1 | 본문 검색 | 중 | 전체 책에서 찾기 → 결과 목록(앞뒤 문맥) → 누르면 그 자리, 찾은 말 표시. EPUB · TXT |

### 3단계 — 독서 기록 (0.15.0) — **완료** (결정 N1–N9. 쪽을 넘는 "이어서 선택" 과 3-5 는 0.17.0)

| # | 기능 | 내용 |
|---|---|---|
| 3-1 | 글자 고르기 | 길게 눌러 선택, 손잡이로 넓히기(쪽을 넘어 이어 고르기는 리디식 "이어서 선택") |
| 3-2 | 복사 · 공유 · 사전/번역 앱으로 보내기 | 공유는 시스템 공유창. 사전 · 번역은 **설치된 앱으로 넘긴다**(ACTION_PROCESS_TEXT) — 인터넷 · 권한 없이 사전 기능을 얻는다 |
| 3-3 | 형광펜 · 메모 | 색 3–4가지, 메모 한 줄. 저장은 Locator 구간(글자 크기를 바꿔도 제자리). DB 이전(Room 스키마 2) |
| 3-5 | 형광펜 보기 | 켬/끔 — 칠한 곳을 잠시 숨긴다 (R6) |
| 3-4 | 독서노트 | 목차 · 책갈피 옆에 "노트" 탭, 누르면 그 자리. 내보내기는 텍스트로 공유 |

### 4단계 — 듣기 · 자동 (0.16.0) — **완료** (결정 L1–L8, 화면 끄고 듣기 포함)

| # | 기능 | 내용 |
|---|---|---|
| 4-1 | 듣기(TTS) | 기기의 음성 엔진(추가 용량 없음), 속도, 읽는 문장 표시, 쪽 자동 넘김, 종료 예약 |
| 4-2 | 화면 끄고 듣기 | 백그라운드 재생 = 포그라운드 서비스 + 알림 → **권한 2개(알림 · 포그라운드 서비스)** 필요 |
| 4-3 | 자동 넘김 | n초마다 다음 쪽(자동 스크롤 대신 — 스크롤 보기가 없으므로) |

### 권하지 않거나 미루는 것

| 기능 | 판단 | 까닭 |
|---|---|---|
| 스크롤 보기 | 제외 권장 | 조판 · 캐시 · 위치가 모두 "쪽" 단위다. 쪽 넘김과 두 벌을 유지하는 비용이 크고 e-ink 원형과도 멀다 |
| 작품별 보기 설정(리디식) | 보류 | 전역 한 벌이 "간편" 에 맞다. 원하면 1단계 뒤에 "이 책만" 토글로 |
| 클라우드 동기화 | 제외 | 인터넷을 쓰지 않는 원칙. 기기 간 이동은 v2(KOSync 등) |
| 온라인 사전 | 제외 | 3-2 의 "사전 앱으로 보내기" 로 대신한다 |
| PDF 검색 · 선택 · 듣기 | **다음** | 2026-09-25 결정 '가': 엔진은 그대로, 안드로이드 15+ `PdfRenderer` 글자 API. 구상안부터 |
| 두쪽보기 | **완료(0.13.0)** | 2026-09-24 사용자 결정(S5 조정, T1–T5 권고안). 가로 기본 켬 · 세로는 폭 600dp 이상에서만 · 장 끝 홀수 쪽은 오른쪽 비움 · PDF 표지 따로 |
| PDF 폭 맞춤 | **완료(0.17.0)** | 보기 판 "쪽 맞춤 [쪽 전체\|폭]". 누르면 한 화면씩 내리고 쪽 끝이면 넘긴다 |
| 상/하 터치로 넘기기 | 보류 | 오른쪽 위 모서리 책갈피와 겹친다. 한 손 모드가 맡는다 |
