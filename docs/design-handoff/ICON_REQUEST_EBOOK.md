# OLO eBook 실행 아이콘 다시 그리기 — 확정안 (2026-10-23) · **반영됨: OLO-Design 2e3b100 → 앱 0.56.3**

OLO-Design 세션에 넘기는 청. 아이콘 원본은 OLO-Design 생성기(`appicons/launcher.py --app ebook`)이고, 앱은 생성물을 그대로
넣는다(손으로 고치지 않는다). 이 문서는 무엇을 그릴지만 정한다.

## 왜

사용자 지적: 지금 먹붓 펼친 책(0.32.1)은 쪽의 윗변 · 아랫변이 부풀고 책등이 둥글어 **실제 책 느낌이 없다** — 책보다 "휜 판 두 장".
실제 책으로 읽히는 신호(쪽보다 큰 각진 표지 판 · 쪽 뭉치 두께 · 책등 골)가 빠져 있었다.

## 결정 순서

1. 안 A "펼친 하드커버 + 책갈피 끈" (B 세운 책 · C 넘어가는 쪽 대신). 끈은 앱 정의("읽고 책갈피를 꽂는다")와 맞는다.
2. 선은 계열 아이콘(폴더 · 재생 · 달력)처럼 **굵기 강약 있는 붓 획** + 반투명 흰 채움. 끈은 흰색(계열 "흰 그림" 규칙 그대로).
3. "선이 겹쳐 두껍다" → **L1 가볍게**: 표지 판 윤곽을 없애고 채움만, 획을 계열 굵기로.

## 그릴 것 (512 격자 · 왼쪽 쪽을 그린 뒤 x=256 을 축으로 뒤집어 오른쪽)

| 요소 | 모양 | 칠 |
|---|---|---|
| 바탕 | 지금 계열 클레이 그라데이션 그대로 | — |
| 표지 판 | `M256,182 C220,164 170,160 118,170 L118,342 C170,332 220,336 256,354 Z` — 쪽보다 사방으로 조금 크고 모서리 각짐. **윤곽 없음** | 흰 22% |
| 쪽 | `M254,194 C222,176 178,170 134,176 L134,322 C178,314 222,318 254,336 Z` — 바깥 변은 곧고 윗변 · 아랫변은 책등 쪽으로 휘어 내려감 | 흰 40% |
| 쪽 윤곽 | 윗변 · 바깥 변 · 아랫변을 **변마다 따로 그은 붓 획**(모서리에서 살짝 겹침). 가장 굵은 곳 9, 끝 3 | 흰 100% |
| 쪽 뭉치 두께 | 아랫변 아래 한 획 `M140,332 C180,324 222,328 252,345`. 굵기 3.6 → 끝 1.4 | 흰 85% |
| 글줄 | 쪽마다 3줄, y = 220 · 250 · 280, x 158 → 232(마지막 줄 200). 굵기 4.5 → 끝 1.2 | 흰 90% |
| 책등 | 가운데 한 획 `M256,192 C255,240 255,290 256,342`. 굵기 9.5 → 끝 3 | 흰 100% |
| 책갈피 끈 | x 284~298, y 196 → 382, 끝은 V(가운데가 10 위로). 아래쪽 양옆에만 가는 윤곽(y 330~383, 굵기 5 → 2) | 흰 72% |

- **붓 획**: 길이를 따라 폭 = 끝 + (가장 굵은 곳 − 끝) × sin(πt)^0.55. 둥근 끝 없이 가늘어져 끝난다.
  - **표의 굵기는 전체 폭(양쪽 합)이다** — 반폭이 아니다. 쪽 윤곽 9 = 중심선에서 양쪽으로 4.5 씩.
  - **떨림은 획 전체에 걸쳐 느리게**: 폭 × (1 + 0.07 × sin(19·t + seed)), t 는 획 길이의 0~1 — 한 획에 물결 세 번 남짓.
    점 번호마다 바꾸면(sin(1.9·i)) 가장자리가 톱니처럼 울퉁불퉁해진다.
- **크기**: 위 좌표를 **(256, 262) 를 중심으로 0.86 배 줄인 것**이 확정 구상안의 크기다(0.95 로 키우지 않는다). 나란히 놓으면 계열 그림(달력 ≈ 아이콘 폭의 55%)보다
  조금 크다 — **생성기가 계열 기준으로 맞춘다**. 108 격자 안전 원(지름 66) 안.
- **흑백 겹**(안드로이드 13 테마 아이콘): 같은 도형 · 같은 투명도. 색은 시스템이 입힌다.
- 구상안 그림(그린 코드 · 사용자 화면이 든 비교판)은 eBook 세션 scratchpad 에만 있다. 사용자 홈 화면 사진이 들어 있어 저장소에 넣지 않는다.

## 1차 생성물(OLO-Design `83c096d`)과 어긋난 점 — 2026-10-23

같은 크기 · 같은 틀로 나란히 그려 쟀다. 앱에 넣지 않았다.

| | 확정 구상안 | 83c096d | 까닭 |
|---|---|---|---|
| 선 굵기 | 쪽 윤곽 9 | 약 18 | 생성기가 표의 굵기를 반폭으로 썼다(`brush` 의 half-width) |
| 가장자리 | 매끈하게 세 번 남짓 물결 | 톱니처럼 울퉁불퉁 | 떨림을 점 번호마다 바꿨다(`sin(i * 1.9 + seed)`) |
| 크기 | 0.86 배 | 0.95 배(더 큼) | 계열 맞춤이 키우는 쪽으로 갔다 |
| 글줄 | 가는 획 | 굵은 알약 | 위 반폭 문제 |

2차 생성물 `2e3b100` 은 세 점을 모두 고쳐 구상안과 같은 틀에서 맞았다(가장 먼 점 140.3/512) — 0.56.3 에 넣었다.
