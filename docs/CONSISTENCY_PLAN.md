# 책장 다듬기 · 머리 정리 · 용어 통일 · 설정 정합성 계획 (2026-10-03 확정: 권고안)

사용자 요청(0.41.0 사용 뒤):

1. 책장을 참고 그림처럼 — **가안(원목) + 갈래 이름은 판 앞면 + 맨 위 가로 칸막이**(사용자 결정)
2. 머리의 "OLO eBook" 줄을 없애고 찾기 · 새로고침 · 폴더 · 정보를 보기 도구 줄로
3. 용어 통일 — "읽는 책 · 읽은 책 · 읽을 책"(이전 확정)인데 책 · 만화가 다른 말을 쓴다
4. 만화의 가로 두 쪽 · 세로 두 쪽이 제대로 듣지 않는다(책에서 정비한 설정)
5. 그 밖의 짜임새도 전반 점검

구상안 그림: wood-board · wood-board-2 · wood-board-3(작업 공간, 저장소에 넣지 않음).

## 1. 원인 — 만화 두 쪽 보기

만화 뷰어는 자기 설정 `comicSpread`(끔 / 넓은 화면에서 / 가로에서 / 늘)만 읽는다. 그런데 만화의 "모든 보기 설정" 은 책과
같은 화면(`CpViewSettingsScreen`, `pdf = true`)이라 **"가로에서 두 쪽 보기" · "세로에서 두 쪽 보기" · "두 쪽 보기에서 표지"**
가 보인다. 이 세 줄은 만화에서 아무것도 바꾸지 않는다(ComicReader.kt 가 `twoPagesLandscape` · `twoPagesPortrait` ·
`pdfCoverAlone` 을 읽지 않는다). 같은 기능에 설정이 두 벌이라 생긴 일이다.

## 3. 점검 — 화면 문구

- 서가: 책 "읽는 중 · 읽은 책 · 읽을 책", 만화 "읽는 중 · **다 읽은 작품** · 읽을 작품". 정한 "읽는 책" 은 어디에도 없다.
- 옮기기: "읽은 책으로 옮기기 / 읽는 중으로 되돌리기" 와 "다 읽은 작품으로 옮기기 / 읽을 작품으로 되돌리기".
  한 번도 있던 적 없는 칸으로 가는데 "되돌리기".
- 찾기 결과 꼬리표 "읽는 중 42%", 순서 판 "읽는 중 · 읽은 · 읽을 **갈래**"(화면에 없는 낱말).
- 웹툰인데 "권": "같은 권 N곳", "마지막 권입니다", "어느 권을 뺄까요?". 작품 화면 머리 "권 · 12"(순서 거꾸로).
- 이어 읽기: 만화만 "이어 보기" · "이어서 보기".
- 홈 / 서재 혼용: "홈으로" · "서재로", "홈에서 새로고침" · "서재에서 새로고침".
- 만화를 못 열어도 "이 책을 열지 못했습니다" · "책을 여는 중…".
- 두 쪽 보기: 책은 켬/끔 두 줄, 만화는 넷 중 고르기("늘" — 다른 곳은 "항상").
- 켬/끔 순서: 넘김 진동만 "끔, 켬".
- 빈 책갈피 안내가 만화 · PDF 에서 문장이 다르다. 부탁하는 말 "-세요 / -해 보세요 / -해 주세요" 섞임.
- "형광펜과 메모" · "형광펜 · 메모" 섞임.
- 가운뎃점 띄어쓰기 · "쪽"(페이지 없음) · 합니다체는 이미 고르다.

## 4. 결정할 것 (★ 권고)

1. 머리 — ★ 가: 탭 줄이 맨 위, 그 아래 한 줄 "순서 ▾ · 찾기 · [격자|목록|책장] · 더 보기(새로고침 · 책 폴더 · 앱 정보)".
   나: 탭 줄 오른쪽에 찾기 · 새로고침 · 폴더 · 정보를 다 늘어놓기(탭이 좁아진다). 어느 쪽이든 "책 14권 · 만화 5작품" 줄은
   탭 숫자와 겹쳐 지운다. 폴더가 없을 때는 가운데 "폴더 추가" 와 더 보기만.
2. 책장 — 사용자 결정대로 가안 + 판 앞면 이름 + 맨 위 칸막이. ★ 판 앞면 글자는 새긴 듯(밝은 글자 + 아래 1dp 그늘).
   ★ 어두운 테마는 같은 결을 낮춘 색. ★ 빈 판은 화면 끝까지.
3. 서가 이름 — ★ 두 탭 모두 "읽는 책 · 읽은 책 · 읽을 책". 세는 단위만 책 "권", 만화 "작품"(만화는 작품으로 묶이므로).
   옮기기 메뉴 · 알림도 같은 세 이름으로 "○○으로 옮기기 / 옮겼습니다"(되돌리기 없앰). 찾기 꼬리표 · 순서 판도 같은 말.
4. 그 밖의 문구 — ★ 아래 용어집대로 한 번에.
5. 만화 두 쪽 — ★ 책과 같은 두 줄(가로에서 · 세로에서 두 쪽 보기, 켬/끔)과 "두 쪽 보기에서 표지" 를 만화도 그대로 따른다.
   만화만의 `comicSpread` 는 없앤다(설정 한 벌). 기본값은 지금 책과 같다(가로 켬, 세로 켬 — 세로는 넓은 화면에서만).
6. 보이는데 듣지 않는 설정 — ★ 만화에는 **적용**: 자동 넘김, 왼쪽 끝 밝기, 하단 정보(시계 · 배터리 등). ★ 만화의 넘김
   효과 줄은 숨김(붙은 밀기로 정함, 결정 7). ★ 웹툰에는 맞지 않는 줄을 숨김: 두 쪽 셋, 넘김 효과 · 소리 · 진동, 자동 넘김,
   왼쪽 끝 밝기(세로 스크롤과 겹침). 웹툰의 하단 정보는 적용. ★ PDF 폭 맞춤이면 두 쪽 줄을 흐리게 + "폭 맞춤에서는 한 쪽씩".

## 5. 순서 (진행: V1 0.42.0 · V2 0.43.0 끝)

책장 이름 자리는 사용자 정정대로 **각 칸 위 칸막이**(맨 위 칸막이 = 첫 칸 이름), 글자 · 첫 표지는 격자 · 목록 보기와 같은 시작선.


V1 설정 한 벌(두 쪽 통일 · 보이는데 듣지 않는 줄 적용/숨김) → V2 용어 통일(문구 전수) → V3 머리 정리 + 책장 다시 그리기.
각 단계에 일부러 망가뜨린 입력 시험(옛 `comicSpread` 저장 값, 숨긴 줄이 다시 나타남, 웹툰에 "권")을 함께 둔다.
