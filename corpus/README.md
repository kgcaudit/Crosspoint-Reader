# 테스트 코퍼스

파서·조판 골든 테스트가 읽는 실제 파일을 여기 둔다. **파일 자체는 저장소에 커밋하지
않는다**(저작권·용량). 각자 로컬에 배치하고, 없으면 해당 테스트는 건너뛴다.

```
corpus/
├─ epub/     EPUB 20권  — 소설·인문·기술서 섞어서. 한국어 위주
├─ txt/      TXT 10개   — UTF-8 / UTF-16 / EUC-KR(CP949) 혼합. 인코딩 감지 검증용
└─ pdf/      PDF 10개   — 텍스트 PDF · 스캔 PDF · 대용량(100MB+) 혼합. 메모리 검증용
```

## 골든 파일

`corpus/golden/<파일명>.json` 에 기대값을 둔다. 이건 커밋한다(텍스트라 작고, 회귀
감지의 기준이므로).

- 파서 골든: 제목 · 저자 · spine 수 · TOC 항목 수 · 감지된 인코딩
- 조판 골든: `FakeMeasurer` 기준 페이지별 시작 글자 오프셋

조판 골든이 바뀌면 **diff를 반드시 눈으로 본다.** 줄바꿈 로직 변경의 영향 범위가
그대로 드러나는 자리다.

## 채우는 방법

1. 보유한 EPUB/TXT/PDF를 위 폴더에 넣는다
2. `./gradlew :document:test -Pcorpus=../corpus` 로 골든을 생성한다 (R1.10에서 구현)
3. 생성된 골든을 눈으로 검수한 뒤 커밋한다
